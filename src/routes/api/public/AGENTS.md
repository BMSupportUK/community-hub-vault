# src/routes/api/public rules
- Sports Guide "not working" crosses come from player_channel_health (player reports + the CHANNEL_CHECK login, which /api/public/hooks/channel-check uses only on channels a player recently reported, to avoid provider blocks; the admin Channel status list shares `channelStatus`) plus recent stalls; the `sports` response adds them outside the guide cache so crosses change without a new guide version. Crosses show only from 10 min before an event until it ends; event-only channels (`isEventChannel`) ignore reports outside an open event window and count only that window's problems, so shared feeds never carry crosses between events.
- Sports Guide feed pins each event channel to an exact live playlist name (Replay feeds/categories excluded, unmatched dropped; Channel NN/Boxing NN left to apps), because app fallback word-matching could land on Replay channels.
- Sports Guide EPG completion uses titled matching programmes on continuous official sports broadcasters, the latest matching end across channels, and full-day EPG with bounded caching; unrelated/replay/event-only feeds retain estimates, and end-time changes alter the feed version.
- Competition-only WBBL EPG completion requires an explicit Live women's competition label and exactly one same-channel women's fixture within 30 minutes of slot start; repeats and ambiguous slots retain estimates.
- Category-linked guide channels never resolve to replay feeds unless the guide names a replay, so numbered event feeds (e.g. NFL Sunday Ticket) keep their live channel.
- Every app login credential stores its own BM Player account number (first login keeps the customer's existing number); device unlock accepts only the number of the login that device uses.
- Account-number send: owner-checked remote_unlock_at; unlock screens poll `unlock_status` (one use, 2 min, counts as check-in).
- BM Player login approval: unlock-screen `unlock_status` polls raise a 5-min owner request (bell + push); website pop-up approves via `decide_player_login` (no profile switch), which sets remote_unlock_at; number entry stays as backup.
- Non-website BM Player logins: unlock_status raises a request with a hashed one-time 10-min token emailed to the offsite customer (/player-approve/$token via /api/public/player-approve); admin/management can approve in BM Player › logins via staff_decide_player_login.
- Offsite BM Player approval: QR/email link token = sha256(device token:request id), approving requires the account number (5 wrong = 15-min lock).
- BM Player security rules live in src/lib/player-security.ts (box limit, quiet-box expiry, lockout steps, genuine signer, sharing window); website login sends go through player-security.server.ts queuePlayerLogin so the per-login box limit can hold logins for admin approval.
- Enabler refresh exposes only a capability-verified reference-use boolean alongside task state, allowing both apps to unlock new references without revealing ticket/order IDs or changing the original scope.
- Dashboard-issued installer codes verify admin/management server-side and bind a website code to an app-kind-specific PIN via admin_issue_id; these PINs cannot redeem customer codes or cross installer kinds. Validate selected apps against current available TV builds before issuance.
- Multi/Triple Room household rule lives in src/lib/player-household.ts and runs inside the device-token stream_claim: connections come from the provider login (package as fallback); each claim stores the device's home/away state so one away slot and home-vs-away exclusion are enforced (busy+takeover or refused); VPN claims keep the last non-VPN state so VPNs stay allowed; strikes are household_away events and blocks live on player_login_homes.
- Center Ice EPG shares fixtures between main NHL Center Ice and NHL Set 2 labels only when their stable pre-pipe feed numbers match; the EPG overlay never rewrites Sports Guide channel/playback routing.
- Sports guides keep publication status; headings prefix events, not channels; document scrolling; channels only beneath Available channels; BM loads through hydration/router pending.
- UFC multi-time imports attach all listed channels to every slot. Triller `Event N` becomes channel `Triller TV N`.
- NHL Center Ice treats its listing clock as ET and converts to the correct UK date/time, ignoring supplied UK clocks; NFL Sunday Ticket and NBA League Pass use stated UK times.
- Sports formats need split/safety/read-back tests; normalize dual-clock typos before title pairing; DAZN inline slots stay separate, qualifiers extend titles.
- Manual sports splits preserve both halves; only adjacent headings move, and shared headings copy to the second half.
