# BM TV Enabler for Windows

Free, unsigned per-user installer for Windows 10/11 x64. No paid signing, BM login, Android phone, Java or Android Studio required. Windows may display an unknown-publisher / SmartScreen warning; organisation-managed PCs may block unsigned applications. Never disable Windows security software.

## Customer setup
The app is a step-by-step wizard, the same flow as the phone BM TV Enabler: each step is checked on the TV before the next unlocks.
1. Download BM TV Enabler Setup from Install Guides → TV Remote Enabler → Windows.
2. Run the installer. If SmartScreen offers it, choose More info → Run anyway only for the download obtained directly from BM Support. Follow the installer and launch BM TV Enabler.
3. Step 1 — Enable TV debugging: the app shows the exact setting for each TV type — ADB debugging (Fire TV: Settings → My Fire TV → Developer options) or Network/Wireless debugging (Android / Google TV: Settings → System → Developer options). If Developer options is hidden, open About and press the device name / Android TV OS build seven times, then go back. Confirm to continue.
4. Step 2 — Check your TV: connect the computer and TV to the same home network (avoid guest Wi-Fi, disconnect VPN; allow Windows network access for your trusted private home network only). Press Find my TV and explicitly select the correct named TV, or enter the TV address. No device is selected or enabled automatically. The app checks what is already set up — an already-ready TV skips straight to confirmation and opens BM Remote Helper; nothing is reinstalled.
5. Step 3 — Confirm your TV type (only when setup is not detected): choose Amazon Fire TV or Android / Google TV, the same type as your ticket or order.
6. Steps 4–6 — Install BM Remote Helper, install remote control, activate: one step at a time, with progress text while the app downloads the latest BM Remote Helper from bmsupport.uk, sends it to the TV, installs the bundled BM Remote Control and enables its Accessibility service without removing other services. On the TV, approve Allow USB debugging? and tick Always allow from this computer.
7. Step 7 — Confirm TV setup: the app re-checks the TV inside the wizard. When everything checks out, setup is finished and BM Remote Helper stays open on the TV showing its six-digit code — type that code on your ticket or order's Remote setup tab. The eight-digit website linking code is optional and never blocks finishing TV setup.
8. Close this Windows app. In your support ticket or order, enter the six-digit TV code only when staff request screen sharing, then approve the connection/screen-sharing prompt on the TV. Use Open BM Remote Helper on TV to show my code to get a fresh code after a call ends; Reset setup starts again without uninstalling TV apps or removing authorization.
9. End support from the ticket/order or TV Helper when finished. The Windows app does not start a support session or let anyone view your TV by itself.

The TV's debugging switch is a manual TV-side prerequisite; this program cannot remotely turn a closed debugging switch on. Setup normally persists through restarts. If connection fails later, check the TV's current address. Factory reset or TV software changes may require setup again. Do not forward port 5555 on your router or expose debugging to the internet.

## Maintenance
Source is separate from the web app. Package with @electron/packager (win32 x64, `--no-asar` so adb.exe and its DLLs remain directly executable), bundling official Google platform-tools adb.exe, AdbWinApi.dll and AdbWinUsbApi.dll plus Google's NOTICE.txt. Compile installer.nsi with NSIS, supplying APPDIR and OUTPUT. Electron loads the static relative-path dist/index.html: the site's Vite config is deliberately unchanged. Pin versions and verify downloaded tools against `release.json`; Google's latest URL is mutable, so stop if its checksum changes until intentionally updating the release.

Run regressions with `bun test windows-tv-enabler/tests`. Physical Windows/Fire TV testing remains necessary. ADB uses an isolated server port 5038 and keys in the app's per-user data directory. No credentials or ADB private keys are distributed in releases.
