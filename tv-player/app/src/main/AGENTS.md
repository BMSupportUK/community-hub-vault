# tv-player main source set rules
- Admin/management announcements are one-off: the server ends a row 3 minutes after sending; the newest active player_announcements row is served by the device-token `announcement` action (10s shared cache); every app checks it every 15s and draws a closable bottom bar over every screen only if the app was already open when it was sent (server age_ms vs app start) (Android adds it to the window decor; desktop shrinks screens so video never covers it); a closed announcement id is remembered per device. Android keeps the bar clear of system-bar insets, closes it on a bar tap and catches Back in dispatchKeyEvent before the screen's own Back.
- Major announcements are a separate player_major_announcements list (admin tab of its own), served by the device-token `major_announcements` action (30s shared cache); apps poll every 60s and show a top-right icon with an unread counter (seen ids stored per device); Android draws it as a round 44dp button with a red count bubble only on the MainActivity home screen, and every header keeps PlayerApplication.MAJOR_ICON_SLOT_DP free on its right so it never covers buttons, never over full-screen video; a signed-out, still-locked (account number not yet entered) or unlinked app shows no icon and keeps no list; the server returns an empty list to devices not linked to a member (Windows/Mac gate on the unlocked state).
