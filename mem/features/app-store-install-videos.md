description: Required format and privacy treatment for Android TV and Amazon Fire TV installation guides
type: feature

- Produce Android TV and Amazon Fire TV installation guides as separate motion-graphics videos.
- Both guides use a friendly British female voice and show the Downloader installation route.
- Show `bmsupport.uk/1234567` only as a clearly labelled example address; never show a live personal download address.
- Do not expose real names, emails, prices, credentials, or other private account details.
- Review files must not replace live install-guide videos until separately approved.
- The iPhone Purple Player Lite guide starts with finding and installing the app, then uses the provider-supplied **BM Secure Code**, followed by the member's app username and password.
- The BM Secure Code is separate from QD DNS codes and is not described as Purple Player Lite's own code.
