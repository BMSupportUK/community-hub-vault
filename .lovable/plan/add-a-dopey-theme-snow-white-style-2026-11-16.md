# Add a "Dopey" theme (Snow White style)

## What you'll get
- A new theme called "Dopey" in a new **Cartoons** group in BM Player (boxes, Windows, Mac), appearing automatically with no app update.
- A storybook-style illustration: a cheerful, beardless young dwarf with big ears, an oversized purple cap and a long green tunic, in a sunny enchanted forest with a little cottage, a diamond mine entrance, sparkling gems and woodland animals.
- Middle of the picture kept calmer and lighter so the home tiles stay readable.

## Note on the picture
Disney owns the actual Dopey character design, so the picture will be an original fairy-tale artwork inspired by him, not a copy of the Disney film image, with no logos or text.

## Steps
1. Generate the 1920x1080 picture, compress it and add it with the other theme pictures.
2. Add the theme under group "Cartoons" with a purple accent colour.
3. Publish the website and confirm the picture loads and the theme is switched on.

## Technical details
- File `public/player-themes/dopey-v1.jpg` (quality ~84).
- Insert `player_themes` row: name "Dopey", grp "Cartoons", sort 80, enabled true, accent #7C3AED.
