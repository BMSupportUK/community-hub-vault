# Only Fools and Horses theme: "Jolly Boys' Outing"

## What you'll get
- A new theme called **Jolly Boys' Outing** in a new **TV Shows** group.
- An illustrated seaside scene in Margate: a man in a 1980s suit and a phone box on the seafront, chatting on the phone, while behind him a cream-and-red 1980s coach blows up in a cartoon-style burst of smoke and flame. Deckchairs, the beach, a pier and a sunny sky fill out the background.
- It's drawn as an original illustration in the spirit of the episode. It won't copy the real actors' faces, the show's logo or stills from the BBC, because the BBC and the actors own those.
- The middle of the picture stays lighter so home-screen tiles are easy to read, like the other themes.

## How it goes live
1. Create the picture, sized 1920x1080 and compressed like the other theme pictures.
2. Add it to the theme list under TV Shows, switched on, with a warm orange accent colour.
3. Publish the website, then check the picture loads from bmsupport.uk and shows up in the theme list the apps read.
4. Boxes, Windows and Mac pick it up the next time they check for themes. No app update needed.

## Technical details
- File: `public/player-themes/jolly-boys-v1.jpg` (quality around 84).
- New `player_themes` row: name "Jolly Boys' Outing", grp "TV Shows", sort 80, enabled true, accent #EA580C, id gen_random_uuid().
- Check the result with the live `themes` endpoint, using a temporary test device that gets deleted afterwards.
