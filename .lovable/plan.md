# Amazon Fire TV connection: no 4-digit code (already live)

No changes are needed. The new BM TV Enabler versions (phone 1.20 and Windows 1.10) already work this way and are the current downloads.

How a customer connects a Fire TV now:
1. Switch on ADB debugging on the Fire TV.
2. In BM TV Enabler, choose the Fire TV or type its address, then press Connect to this TV.
3. On the TV, tick Always allow and press Allow.
4. Setup runs by itself straight away. No 4-digit code is asked for.

Android / Google TVs work the same way. On Windows, they can also use Pair with code from the TV's Wireless debugging screen.
